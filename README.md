# Kenari Tasikmalaya

**Canary Pedigree & Breeding Management** — Android-native application for canary identity, ring IDs, photos, pedigree, and breeding records.

- Package: `com.winsmediatama.kenari`
- Platform: Android Native / Kotlin / Jetpack Compose
- Local-first database: Room (planned in core implementation)
- UI: Material 3, premium Forest Green / Ivory / Soft Gold

## Development
Open the project in Android Studio and run the `app` configuration.

## Roadmap
1. App foundation, premium UI, dashboard, navigation.
2. Canary CRUD, ring ID uniqueness, photo picker/camera, type catalog.
3. Parent selection from existing birds and inline creation of new parents.
4. Multi-generation pedigree tree and ancestry/descendant navigation.
5. Breeding pair records, hatchlings, reports, PDF/CSV.
6. Backup/restore, QR ring profiles, pedigree relationship warnings.
